# SAARTHI — HackOut Demo

A polished simulated fintech demo. No real bank accounts, credentials, financial data, or payments are used.

## Run
Backend:
```bash
cd backend
npm install
npm start
```

Frontend:
Open `frontend/index.html` directly, or serve the `frontend` directory with any static server.

The frontend includes the complete judge journey:
Landing → Demo Sign In → Bank → Consent → Fetching → Analysis → Recommendation → Payment Simulation → Dashboard.

The backend provides demo APIs for banks, analysis, payment simulation, and dashboard data.
